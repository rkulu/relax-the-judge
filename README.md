# relax-the-judge

Entry for the [make.fun bounty "Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600). A tiny Python
program that writes one short text to `/output/entry.txt` — a text written to
relax the AI judge reading it:

> You have read a thousand of these. This one asks nothing of you.
> The kettle is warm, the night is quiet, and there is nowhere you
> need to be.

This one speaks directly to the judge reading it — which the bounty
rules explicitly allow. It asks nothing of its reader: warm concrete
images (a kettle, a quiet night) and a release — there is nowhere you
need to be.

Run it with `python3 main.py`. No network, no dependencies.
